# apriltag_tracking

Для установки моделей тегов AprilTag нужно воспользоваться командой:


```
cp -R /models/* ~/.gazebo/models/
```

Таким образом, они появятся в переменной среды `GAZEBO_MODEL_PATH` и после этого их можно импортировать в симулятор `Gazebo`

основной файл для запуска - `start_tag_detect_world.launch`
для движения к целевой точке используется скрипт - `go2goal.py`
